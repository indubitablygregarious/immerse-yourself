# 2026-03-01

Code quality sweep driven by SonarCloud findings. Cleaned up all the Rust warnings — unused imports, dead code, visibility issues. Fixed a ThemeContext provider re-render bug that SonarCloud flagged; the context was causing unnecessary re-renders throughout the component tree. Switched the Makefile to use cargo-binstall for tauri-cli installs, which is faster than compiling from source. The biggest architectural change was ripping out the entire download infrastructure and replacing it with manifest-only sound resolution — runtime downloads were already disabled, so all that code was dead weight. Sounds now resolve purely through the manifest and local cache. Filed #51 to track the remaining 137 SonarCloud findings.
